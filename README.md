# Zuma In 3D
 
Прототип игры, вдохновленный игрой Zuma 2003 года. 
Основным вызовом стало написание механизма плавного перемещения шариков по полю змейкой, и их поведение, когда часть шариков уничтожается игроком. Также большой сложностью стала оптимизация.

A prototype of a game inspired by the 2003 game Zuma.
The main challenge was writing a mechanism for smoothly moving the balls along the snake field, and their behavior when some of the balls are destroyed by the player. Optimization was also a significant challenge.
